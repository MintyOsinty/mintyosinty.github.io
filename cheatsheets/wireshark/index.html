--- layout: default title: Wireshark Cheat Sheet description: Copy-and-paste Wireshark display filters for finding specific connections, protocols, problems and suspicious traffic. sections: - id: who title: Who's Talking intro: Narrow things down to one machine, one network or one device. items: - f: 'ip.addr == 192.168.1.10' d: Everything to or from one IP address. - f: 'ip.src == 192.168.1.10' d: Only traffic that IP is sending. - f: 'ip.dst == 192.168.1.10' d: Only traffic going to that IP. - f: 'ip.addr == 192.168.1.10 && ip.addr == 8.8.8.8' d: Just the conversation between two hosts. - f: 'ip.addr == 192.168.1.0/24' d: Anything on a whole subnet. - f: '!(ip.addr == 192.168.1.10)' d: Hide one noisy host. - f: 'eth.addr == aa:bb:cc:dd:ee:ff' d: A specific device by MAC address. - id: ports title: Ports & Protocols intro: Find connections by service. Typing a protocol name alone (like ssh) also works. items: - f: 'tcp.port == 443' d: One TCP port, either direction. - f: 'udp.port == 53' d: One UDP port, either direction. - f: 'tcp.dstport == 3389' d: Connections going to a port (here, RDP). - f: 'tcp.port in {80 443 8080}' d: Several ports at once. - f: 'ssh' d: SSH sessions. - f: 'rdp' d: Remote Desktop. - f: 'smb || smb2' d: Windows file sharing. - f: 'dhcp' d: Devices asking for an IP address (joining the network). - f: 'arp' d: Who-has-this-IP chatter on the local network. - f: 'icmp' d: Pings and other ICMP messages. - id: tcp title: TCP Connections intro: Watch connections open, get accepted, get refused and close. items: - f: 'tcp.flags.syn == 1 && tcp.flags.ack == 0' d: New connection attempts (the first SYN). - f: 'tcp.flags.syn == 1 && tcp.flags.ack == 1' d: Connections a server accepted (SYN/ACK). - f: 'tcp.flags.reset == 1' d: Resets. Connections refused or killed. - f: 'tcp.flags.fin == 1' d: Connections closing normally. - f: 'tcp.stream eq 5' d: One single conversation. Right-click a packet → Follow → TCP Stream sets this for you. - f: 'tcp.len > 0' d: Only packets that actually carry data (skips the bare ACKs). - id: web title: Web & DNS intro: See what sites and names a machine is reaching for. items: - f: 'dns' d: All DNS lookups and answers. - f: 'dns.flags.response == 0' d: DNS questions only. - f: 'dns.qry.name contains "example"' d: Lookups for a specific domain. - f: 'dns.flags.rcode == 3' d: Lookups for names that don't exist (NXDOMAIN). - f: 'http.request' d: Every HTTP request. - f: 'http.request.method == "POST"' d: Form submissions and uploads. - f: 'http.response.code >= 400' d: HTTP errors (404s, 500s and friends). - f: 'tls.handshake.type == 1' d: The start of every HTTPS connection (Client Hello). - f: 'tls.handshake.extensions_server_name contains "example"' d: Which HTTPS site was visited, even though the traffic is encrypted. - id: problems title: Network Problems intro: Start here when the network feels slow or flaky. items: - f: 'tcp.analysis.flags' d: Every TCP problem Wireshark noticed, all at once. - f: 'tcp.analysis.retransmission' d: Packets that had to be re-sent. Lots of these means loss. - f: 'tcp.analysis.zero_window' d: A receiver too busy to accept more data. - f: 'icmp.type == 3' d: Destination unreachable messages. - f: '!(arp || dns || icmp || ssdp || mdns || llmnr || nbns)' d: Hide the background chatter so the real traffic stands out. - id: security title: Suspicious Stuff intro: Quick hunts for things that shouldn't be there. items: - f: 'tcp.flags.syn == 1 && tcp.flags.ack == 0 && tcp.window_size <= 1024' d: Tiny-window SYNs, a classic sign of an Nmap SYN scan. - f: 'tcp.port == 4444' d: Metasploit's default listener port. - f: 'arp.duplicate-address-detected' d: Two devices claiming the same IP, a possible ARP spoof. - f: 'ftp || telnet' d: Old protocols that send logins in plain text. - f: 'ftp.request.command == "PASS"' d: FTP passwords sent in the clear. - f: 'http.authorization' d: HTTP logins (often just base64, not encryption). - f: 'frame matches "(?i)password"' d: Any packet containing "password", any capitalization. - f: 'http.user_agent contains "python"' d: Scripts and tools instead of real browsers. capture: - f: 'host 192.168.1.10' d: Only record traffic to or from one IP. - f: 'net 192.168.1.0/24' d: Only record one subnet. - f: 'port 53' d: Only record one port. - f: 'not port 22' d: Record everything except SSH (handy when you're connected over SSH). ---
